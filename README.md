# హరిపాలెం గ్రామ పంచాయతీ ఓటర్ల సమాచార & PDF సేకరణ వ్యవస్థ – 2026
## Haripalem Telugu Voter Information & PDF Extraction System

2026 ఆంధ్రప్రదేశ్ గ్రామ పంచాయతీ సాధారణ ఎన్నికల హరిపాలెం గ్రామ పంచాయతీ ఓటర్ల జాబితా (మొత్తం 2,856 ఓటర్లు, 12 వార్డులు) కొరకు రూపొందించబడిన పూర్తి స్థాయి వెబ్ అప్లికేషన్.

ఈ అప్లికేషన్ ద్వారా ఏ ఓటరు వరుస సంఖ్య (1 నుండి 2856) నమోదు చేసినా, అసలు ఓటర్ల జాబితా PDF లోని సంబంధిత వ్యక్తి నమోదిత విభాగాన్ని (ఫోటో, తెలుగు ఫాంట్లు, సరిహద్దులు మరియు వివరాలతో సహా) ఖచ్చితమైన నాణ్యతతో వెలికితీసి, ప్రత్యేక PDF పత్రంగా అందిస్తుంది.

## 1. ప్రాజెక్ట్ లక్షణాలు (Key Features)

- **అసలు రూపం యథాతథ సంరక్షణ (Pure Vector PDF Extraction):**
  - ఓటరు ప్రవేశాన్ని HTML ద్వారా పునర్నిర్మించడం గానీ, రీ-డిజైన్ చేయడం గానీ జరగదు.
  - అసలు PDF లోని వెక్టర్ గ్రిడ్ నుండి PyMuPDF (`fitz`) ద్వారా `show_pdf_page` మరియు ఖచ్చితమైన బౌండింగ్ బాక్స్ క్లిప్పింగ్ ద్వారా సేకరించబడుతుంది.
  - తెలుగు అక్షరాలు (Nirmala UI Typography), ఓటరు ఫోటో నాణ్యత, ఒరిజినల్ సరిహద్దులు, వివరాలు చెక్కుచెదరకుండా ఉంటాయి.
- **సంపూర్ణ తెలుగు ఇంటర్‌ఫేస్ (100% Telugu User Interface):**
  - శీర్షికలు, లేబుల్స్, బటన్లు, డ్యాష్‌బోర్డ్, శోధన ఫలితాలు, హెచ్చరికలు మరియు నోటీసులు అన్నీ స్వచ్ఛమైన తెలుగులో రూపొందించబడ్డాయి.
- **తక్షణ శోధన (Instant Lookup with SQLite Indexing):**
  - మొదటిసారి ప్రారంభంలో 2,856 ఓటర్ల వివరాలు, పేజీ సంఖ్య, నిలువు మరియు అడ్డు వరుసల సరిహద్దులు SQLite డేటాబేస్ (`voters.db`) లో ఇండెక్స్ చేయబడతాయి.
  - తదుపరి ప్రతి శోధన 1 మిల్లీసెకను లోపే ఫలితాన్ని అందిస్తుంది.
- **ప్రత్యేక పి.డి.ఎఫ్ మరియు ప్రివ్యూ (PDF Generation & Instant Preview):**
  - వెబ్ పేజీలో అసలు ఎంట్రీ యొక్క హై-రిజల్యూషన్ చిత్ర ప్రివ్యూ కనిపిస్తుంది.
  - ఒక్క క్లిక్‌తో డౌన్‌లోడ్ చేసుకోగల ప్రత్యేక సింగిల్ పేజీ PDF లభిస్తుంది.
  - పత్రం వెలుపల తప్పనిసరి చట్టబద్ధమైన గమనిక ముద్రించబడుతుంది:
    *`అనధికారిక ఓటరు సమాచారం ప్రతీ — గుర్తింపు పత్రం కాదు`*
- **కచ్చితమైన ఇన్‌పుట్ ధృవీకరణ (Validation):**
  - ఖాళీ ఇన్‌పుట్, సంఖ్యలు కాని అక్షరాలు, మరియు 1-2856 పరిధి దాటిన సంఖ్యలను తెలుగులోనే హెచ్చరిస్తుంది.
- **పరీక్షార్థ వరుస సంఖ్యలు (Quick Test Chips):**
  - నిర్దేశిత 16 ముఖ్యమైన వరుస సంఖ్యలను (1, 2, 27, 28, 54, 72, 238, 239, 476, 952, 1190, 1428, 1904, 2380, 2618, 2856) సులభంగా పరీక్షించడానికి క్విక్ బటన్స్ అందుబాటులో ఉన్నాయి.

## 4. ఇన్‌స్టాలేషన్ మరియు అమలు విధానం (Installation & Setup)

### అవసరమైనవి:
- Python 3.10 లేదా ఆపై వెర్షన్
- Windows / Linux / macOS

### 1. ప్రాజెక్ట్ డైరెక్టరీకి వెళ్లండి:
```powershell
cd d:\votw
```

### 2. పైథాన్ ప్యాకేజీలను ఇన్‌స్టాల్ చేయండి:
```powershell
pip install -r requirements.txt
```

### 3. అప్లికేషన్‌ను ప్రారంభించండి:
```powershell
python app.py
```

అప్లికేషన్ ప్రారంభమైన తర్వాత, బ్రౌజర్‌లో కింది లింక్‌ను తెరవండి:
👉 **`http://localhost:5000`** లేదా **`http://127.0.0.1:5000`**

## 6. గోప్యత మరియు భద్రతా విధానాలు (Privacy & Security Precautions)

- **స్థానిక ప్రాసెసింగ్ (100% Local Processing):** ఓటర్ల జాబితా కేవలం స్థానిక సిస్టమ్‌లోనే భద్రపరచబడి ప్రాసెస్ చేయబడుతుంది.
- **బాహ్య APIలు లేవు:** ఏ విధమైన క్లౌడ్ లేదా ఎక్స్‌టర్నల్ థర్డ్-పార్టీ OCR లేదా AI సేవలకూ సమాచారం పంపబడదు.
- **బల్క్ ఎక్స్‌పోర్ట్ నిషేధం:** బల్క్ డౌన్‌లోడ్ లేదా మాస్ డేటా స్క్రాపింగ్ అనుమతించబడదు. కేవలం అధికారిక సింగిల్ సీరియల్ నంబర్ శోధనలు మాత్రమే పని చేస్తాయి.
- **చట్టబద్ధమైన గమనిక:** డౌన్‌లోడ్ చేయబడిన ప్రతి పి.డి.ఎఫ్ పత్రంలో స్పష్టంగా *«అనధికారిక ఓటరు సమాచారం ప్రతీ — గుర్తింపు పత్రం కాదు»* అని తప్పనిసరిగా ముద్రించబడుతుంది.
